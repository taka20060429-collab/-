## 1. 傾向と難易度

中間試験の10問は、小テスト（静電界及び演習 第1〜5回・第7回、全24問）の数値を変えたものから出る。2024年と2025年は、10問すべてが小テストのどれかと同じ型だった。小テスト24問を全部解けるようにすれば、ほぼ全問に対応できる。

難易度は5段階で2〜2.5。1問ごとの難しさは小テストも過去問も同じくらいで、公式に代入する問題と、ガウスの法則で電場を出して積分する記述問題が中心。差がつくのは、単位換算・符号・距離計算のミスと、記述の途中式。

- 試験：60分、10問。担当は吉田先生（2022・2024・2025年とも）。

- 持ち込み：筆記用具と、履歴を消した関数電卓だけ。

## 2. 公式集

試験で使う公式はこの章のもので全部。$k = 1/(4\pi\varepsilon_0) = 9\times10^9$ N·m²/C² と書く。

### 定数と単位

| 量 | 記号 | 単位 |
|---|---|---|
| 電荷 | $Q$ | C（クーロン） |
| 力 | $F$ | N |
| 電場（電界） | $E$ | V/m = N/C |
| 電位・電位差 | $V$ | V = J/C |
| 線電荷密度 | $\lambda$（問題文では $Q$） | C/m |
| 面電荷密度 | $\sigma$ | C/m² |
| 体積電荷密度 | $\rho$ | C/m³ |
| 真空の誘電率 | $\varepsilon_0 = 8.854\times10^{-12}$ | F/m |
| 誘電率 | $\varepsilon = \varepsilon_r\varepsilon_0$ | F/m（$\varepsilon_r$ は単位なし） |
| 電子・陽子の電荷 | $\mp e = \mp1.602\times10^{-19}$ | C |

接頭辞：m = $10^{-3}$、μ = $10^{-6}$、n = $10^{-9}$、p = $10^{-12}$。1 cm = $10^{-2}$ m、1 g = $10^{-3}$ kg、1 μC/cm² = $10^{-2}$ C/m²。

### クーロンの法則

$$F = \frac{Q_1 Q_2}{4\pi\varepsilon r^2} = k\,\frac{Q_1 Q_2}{r^2}$$

同じ符号なら斥力、異なる符号なら引力。媒質中では $\varepsilon_0$ を $\varepsilon = \varepsilon_r\varepsilon_0$ に置き換える。

### 点電荷の電場（ベクトル）

$$\vec{E} = \frac{Q}{4\pi\varepsilon_0 r^2}\,\hat{r} = \frac{Q}{4\pi\varepsilon_0}\,\frac{\vec{r}-\vec{r}\,{}'}{|\vec{r}-\vec{r}\,{}'|^3}$$

$\vec r^{\,\prime}$ は電荷の位置、$\vec r$ は電場を求める点。複数の電荷があるときはベクトルとして足す（重ね合わせ）。力との関係は $\vec F = Q\vec E$。

### 電位（スカラー）

$$V = \frac{Q}{4\pi\varepsilon_0 r}, \qquad V = \sum_i \frac{Q_i}{4\pi\varepsilon_0 r_i}$$

$$V_A - V_B = -\int_B^A \vec{E}\cdot d\vec{r} = \int_A^B E\,dr, \qquad \vec{E} = -\nabla V$$

符号つきのまま足す（負の電荷は負の電位）。無限遠を基準（0 V）にする。点電荷では $V = Er$ の関係がある（$E = kQ/r^2$、$V = kQ/r$ より）。

### 電気力線

電荷 $Q$ から出る電気力線の本数は $N = Q/\varepsilon$（真空中は $Q/\varepsilon_0$）。閉曲面から出る本数は、中の電荷の合計を $\varepsilon$ で割る。合計が正なら「出る」、負なら「入る」。電気力線の密度（本/m²）は電場の大きさ $E$ に等しい。

### ガウスの法則

$$\oint_S \vec{E}\cdot d\vec{S} = \frac{Q_{\text{in}}}{\varepsilon_0} \qquad\Longleftrightarrow\qquad \nabla\cdot\vec{E} = \frac{\rho}{\varepsilon_0}$$

| 対称性 | ガウス面 | 左辺 | 結果 |
|---|---|---|---|
| 球（点電荷・導体球） | 半径 $r$ の球面 | $E\cdot4\pi r^2$ | $E = Q_\text{in}/(4\pi\varepsilon_0 r^2)$ |
| 無限長の直線・円筒 | 半径 $r$、長さ $l$ の円筒 | $E\cdot2\pi rl$ | $E = \lambda_\text{in}/(2\pi\varepsilon_0 r)$ |
| 無限に広い平面 1 枚 | 平面を挟む円柱（底面積 $A$） | $E\cdot2A$ | $E = \sigma/(2\varepsilon_0)$ |
| 平行平板（$+\sigma$ と $-\sigma$） | 重ね合わせ | ― | 間：$E = \sigma/\varepsilon_0$、外：0 |

### ポアソン・ラプラスの方程式

ガウスの法則（微分形）に $\vec E = -\nabla V$ を代入すると導かれる。

$$\nabla^2 V = \frac{\partial^2 V}{\partial x^2}+\frac{\partial^2 V}{\partial y^2}+\frac{\partial^2 V}{\partial z^2} = -\frac{\rho}{\varepsilon_0}\ \ (\text{ポアソン}), \qquad \nabla^2 V = 0\ \ (\rho=0:\ \text{ラプラス})$$

### その他

- 平行平板コンデンサ：$E = V/d$、$Q = \sigma S = \varepsilon_0 SV/d$、$C = \varepsilon_0 S/d$。
- 導体：内部の電場は 0、全体が等電位。電荷は表面にだけ分布する。
- 静電誘導：導体球殻の内側の面には、中の電荷と同じ大きさで逆符号の電荷が誘導される。

## 3. 型別の解き方

計算型は手順を決めておけば短時間で解ける。記述型は「ガウス面を設定する → ガウスの法則を書く → $E$ を求める → 積分して $V$ を求める」の4行を、そのまま答案に書く。各型の見出しに、その型の小テストの問題番号を書いてある。

### A. 点電荷の電場の大きさ（小3-1, 小3-2）

1. 電荷の座標から点の座標への差を取る（点 − 電荷）。
2. $r^2 = \Delta x^2 + \Delta y^2 + \Delta z^2$ を計算する。平方根はとらなくていい。cm は m に直す。
3. $E = kQ/r^2$ に代入する。

### B. 複数の点電荷による電位（小3-3）

1. 各電荷について、電位を求める点までの距離 $r_i$ を求める。原点とは限らない（2025年は点P）。
2. $V = k\sum Q_i/r_i$ を、符号をつけたまま足す。電位はスカラーなので、向きは考えない。

### C. 一直線上のクーロン力（小1-1, 小1-2, 小2-4）

1. 注目する電荷に、他のそれぞれの電荷から働く力の大きさを $kQ_1Q_2/r^2$ で求める。媒質中は $4\pi\varepsilon$ で割る。
2. 力の向きは図を描いて決める（同符号なら斥力、異符号なら引力）。問題文で決められた「正の向き」に合わせて ± をつける。
3. 符号つきで足す。

文字式で3つの電荷全部の力を聞かれたら（小1-2）、3つの力の和が 0 になることで検算できる。

### D. 電荷を置き換えても力が同じになる位置（小2-2）

元の力 $kQ_AQ_B/r^2$ と、新しい力 $kQ_CQ_B/x^2$ を等しいとおいて $x$ を求める。$x = r\sqrt{Q_C/Q_A}$ とすると、$k$ を使わずに済む。

### E. 糸でつるした2物体のつり合い（小1-3）

1. 2物体の間隔は $r = 2L\sin\theta$（$L$：糸の長さ、$\theta$：鉛直方向からの角度）。
2. 重力 $mg$ は縦、クーロン力 $F$ は横、張力 $T$ は糸の向き。縦：$T\cos\theta = mg$、横：$T\sin\theta = F$。割り算して $T$ を消すと $\tan\theta = F/(mg)$。よって $F = mg\tan\theta$（$\sin$ ではない）。
3. $F = kQ^2/r^2$ を解いて $Q = r\sqrt{F/k}$。質量の g を kg に直すのを忘れない。角度が rad で与えられたら（2025年は $\pi/10$）電卓のモードに注意。

### F. 2つの点電荷による電場をベクトル・成分で表す（小3-5, 小6-3）

原点に $Q_1$、点 $(x_2, y_2)$ に $Q_2$ があるとき、点 $P(x, y)$ では次のようになる。

$$\vec{E} = \frac{Q_1}{4\pi\varepsilon_0}\frac{x\vec{i}+y\vec{j}}{(x^2+y^2)^{3/2}} + \frac{Q_2}{4\pi\varepsilon_0}\frac{(x-x_2)\vec{i}+(y-y_2)\vec{j}}{\{(x-x_2)^2+(y-y_2)^2\}^{3/2}}$$

1. 各電荷から P へのベクトル（P − 電荷）を書き、その長さの3乗で割る。
2. $\vec i$ の係数が $E_x$、$\vec j$ の係数が $E_y$。片方だけ聞かれたら、その係数だけを書く。
3. 数値のときは、電荷ごとに $kQ/r^3$ を先に計算してからベクトルに掛けると速い。P が電荷の真上（$x = 0$）なら、その電荷の $E_x$ は 0（小6-3）。

### G. 電荷量などの逆算（小1-4, 小2-1, 小3-4, 小4-3）

まだ中間試験に出ていない型。式を立てて、求めたいものについて解くだけ。

| 与えられたもの | 求めるもの | 解き方 |
|---|---|---|
| 等しい2電荷の距離 $r$ と力 $F$ | 電荷 $Q$ と符号 | $Q = r\sqrt{F/k}$。反発力なら同符号（正か負かは決まらない）、引力なら異符号 |
| 2電荷の比 $Q_1:Q_2 = m:n$、距離、力 | $Q_1$、$Q_2$ | $Q_1 = mx$、$Q_2 = nx$ とおいて $k\,mn\,x^2/r^2 = F$ を解く。符号は問題文で決める |
| 1点での $E$ と $V$ | $Q$ と $r$ | $V/E = r$ で $r$ が出る。$Q = Vr/k$ |
| 球面上の電場 $E$ と半径 $r$ | 中心の電荷 $Q$ | $Q = Er^2/k$（ガウスの法則 $E\cdot4\pi r^2 = Q/\varepsilon_0$ と同じ） |
| 閉曲面から出る電気力線の本数 $N$ | 中の電荷 | 中の電荷の合計 $= N\varepsilon_0$。わかっている電荷を引く |

### H. 対称な配置の合力（小2-3）

まだ中間試験に出ていない型。y軸上の $(0, \pm a)$ に $+Q$、x軸上の $(x, 0)$ に $+2Q$ がある場合：

1. 2つの $+Q$ から受ける力は、大きさが同じ $k\cdot Q\cdot2Q/(x^2+a^2)$。
2. y成分は打ち消し合う。x成分は $\cos\phi = x/\sqrt{x^2+a^2}$ を掛けて2倍する。

$$F = 2\times\frac{2kQ^2}{x^2+a^2}\times\frac{x}{\sqrt{x^2+a^2}} = \frac{4kQ^2x}{(x^2+a^2)^{3/2}} = \frac{Q^2x}{\pi\varepsilon_0(x^2+a^2)^{3/2}}\quad(+x\text{ の向き})$$

### I. 電気力線の本数（小4-2, 小5-4, 小6-4）

1. 閉曲面の中の電荷を、符号をつけて全部足す。
2. $N = Q_\text{合計}/\varepsilon$。油などの媒質中は $\varepsilon = \varepsilon_r\varepsilon_0$ で、比誘電率は分母に入る。
3. 合計が正なら「出る」、負なら「入る」。本数から電荷を逆算する問題は型Gの最後の行。

### J. 無限長の円筒（記述・小5-1）

半径 $a$、単位長さあたり $Q$ [C/m] の電荷が、円筒の中に一様に分布しているとする。

1. 中心軸が同じで、半径 $r$、長さ $l$ の円筒をガウス面にする。対称性から、$E$ は半径方向を向き、側面上で大きさが一定。上下の底面を通る電束は 0。
2. 外側（$r > a$）：ガウス面内の電荷は $Ql$。

$$E\cdot 2\pi r l = \frac{Ql}{\varepsilon_0}\quad\Rightarrow\quad E_o = \frac{Q}{2\pi\varepsilon_0 r}$$

3. 内側（$r < a$）：単位長さあたりの電荷は断面積の比で $Q\,r^2/a^2$（小5-1(2) はこれを聞いている）。

$$E\cdot 2\pi r l = \frac{Ql}{\varepsilon_0}\frac{r^2}{a^2}\quad\Rightarrow\quad E_i = \frac{Qr}{2\pi\varepsilon_0 a^2}$$

4. 外側の2点 A（$r_1$）と B（$r_2$）の間の電位差（$r_2 > r_1 > a$）：

$$V = V_A - V_B = \int_{r_1}^{r_2}\frac{Q}{2\pi\varepsilon_0 r}\,dr = \frac{Q}{2\pi\varepsilon_0}\ln\frac{r_2}{r_1}$$

電荷が円筒の表面にだけある場合は、ガウス面内の電荷が 0 なので内側の電場は $E_i = 0$ になる。外側の式は同じ。

### K. 平行平板（記述・数値・小5-2, 小6-2）

1. 平面1枚が作る電場は $\sigma/(2\varepsilon_0)$（型L）。$+\sigma$ の板と $-\sigma$ の板を重ね合わせると、板の間では足し合わされ、外側では打ち消し合う。

$$E = \frac{\sigma}{2\varepsilon_0}+\frac{\sigma}{2\varepsilon_0} = \frac{\sigma}{\varepsilon_0}\ (+\text{から}-\text{の向き}), \qquad V = Ed = \frac{\sigma d}{\varepsilon_0}$$

2. 電圧 $V$ を加えたという形で出題された場合（小6-2）：$E = V/d$、各板の電荷は $Q = \sigma S = \varepsilon_0 ES = \varepsilon_0 SV/d$（一方が $+Q$、もう一方が $-Q$）。
3. 数値で出たときは、間隔 $d$ は電位差にだけ使う。電場に $d$ やクーロンの法則は使わない。

### L. 無限に広い平面1枚（記述・小6-1）

1. 平面を垂直に貫く円柱（底面積 $A$）をガウス面にする。対称性から $E$ は平面に垂直で、両側で同じ大きさ。側面を通る電束は 0。
2. ガウス面内の電荷は $\sigma A$。電束は上下2つの底面から出る。

$$E\cdot A + E\cdot A = \frac{\sigma A}{\varepsilon_0}\quad\Rightarrow\quad E = \frac{\sigma}{2\varepsilon_0}$$

3. 向き：$\sigma > 0$ なら両側とも平面から離れる向き。平行平板の $\sigma/\varepsilon_0$ と混同しない。

### M. 導体球・薄い導体球殻（数値・記述・小4-4, 小5-3）

半径 $R$ の導体球（または薄い球殻）に電荷 $Q$ があるとき、電荷はすべて表面に分布する。

| 場所 | 電場 $E$ | 電位 $V$ |
|---|---|---|
| 外側（$r > R$） | $Q/(4\pi\varepsilon_0 r^2)$（中心に点電荷があるのと同じ） | $Q/(4\pi\varepsilon_0 r)$ |
| 内側（$r < R$） | 0 | $Q/(4\pi\varepsilon_0 R)$（表面と同じで一定） |

1. 記述では、半径 $r$ の同心球面をガウス面にする。外側は $E\cdot4\pi r^2 = Q/\varepsilon_0$、内側はガウス面内の電荷が 0 なので $E = 0$。
2. 表面電荷密度 $\sigma$ が与えられたら、$Q = \sigma \times 4\pi R^2$。1 μC/cm² = $10^{-2}$ C/m²。半径の cm も m に直す。
3. 内側の電位は 0 ではない。電場が 0 なので電位が変化せず、表面の値のままになる。

### N. 同心の導体球（記述・小4-1, 小6-5・毎年出ている）

導体1は半径 $a$ で電荷 $+Q$。導体2は内側の半径 $b$、外側の半径 $c$ の球殻で、電荷 $Q_2$。

1. 電荷の分布：導体1の表面（$r = a$）に $+Q$。導体2の内側の面（$r = b$）には静電誘導で $-Q$。外側の面（$r = c$）には残りの $Q_2 + Q$。
2. 半径 $r$ の同心球面をガウス面にすると、$E\cdot4\pi r^2 = Q_\text{in}/\varepsilon_0$。
3. 電位は無限遠から積分する。

| | 導体2が $-Q$（小6-5, 2022, 2024） | 導体2が 0（小4-1, 2025） |
|---|---|---|
| 外側の面の電荷 | 0 | $+Q$ |
| $E_o$（$r > c$） | 0 | $Q/(4\pi\varepsilon_0 r^2)$ |
| $V_o$（$r > c$） | 0 | $Q/(4\pi\varepsilon_0 r)$ |
| $E_i$（$a < r < b$） | $Q/(4\pi\varepsilon_0 r^2)$ | $Q/(4\pi\varepsilon_0 r^2)$ |
| $V_i$（$a < r < b$） | $\dfrac{Q}{4\pi\varepsilon_0}\left(\dfrac1r - \dfrac1b\right)$ | $\dfrac{Q}{4\pi\varepsilon_0}\left(\dfrac1r - \dfrac1b + \dfrac1c\right)$ |
| $V_2$ | 0 | $Q/(4\pi\varepsilon_0 c)$ |
| $V_1$ | $\dfrac{Q}{4\pi\varepsilon_0}\left(\dfrac1a - \dfrac1b\right)$ | $\dfrac{Q}{4\pi\varepsilon_0}\left(\dfrac1a - \dfrac1b + \dfrac1c\right)$ |

導体2が 0 のときの記述の流れ：

$$V_2 = -\int_{\infty}^{c}\frac{Q}{4\pi\varepsilon_0 r^2}\,dr = \frac{Q}{4\pi\varepsilon_0 c},\qquad V_1 = V_2 - \int_{b}^{a}\frac{Q}{4\pi\varepsilon_0 r^2}\,dr = \frac{Q}{4\pi\varepsilon_0}\left(\frac{1}{a}-\frac{1}{b}+\frac{1}{c}\right)$$

$b < r < c$（導体2の内部）は電場 0 なので、$r = b$ と $r = c$ の電位は等しい。

## 4. 小テスト 全問解答（最重要）
